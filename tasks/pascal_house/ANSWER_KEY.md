# PH-1 answer key (withheld)

The MARB-A PH-1 answer key is **not** in this repository and never has been —
unlike the task-1 key it was born outside the public tree. It is withheld to
prevent training-data contamination, not as a secrecy measure.

Two files make up the key:

- `ph1_reference_layout.yaml` — walls, openings, furnishings, tolerances, BOM.
- `ph1_reference_scene.json` — the key realized as a Pascal-shaped scene
  (generated by `pascal_scene_grade.py --emit-ref-scene`); used by the grader
  self-test.

## Get it

While the architecture lane is pre-v1 the key is shared on request:
info@sunn3d.com. When the lane stabilizes it moves to a gated Hugging Face
dataset alongside the M3 key (see the answer-key section of
[PUBLISHING.md](../../PUBLISHING.md)).

Place both files in this directory (`tasks/pascal_house/`); the grader
defaults point here. The paths are gitignored, and the pre-push hook plus the
`key-guard` CI workflow reject any commit that tries to add them.

## Integrity (sha256)

All published PH-1 grades were produced against exactly this key revision:

```
46eadaf7b20e791ba71752ac42f2ab1ef79ce04df99ddfb0a2fd2a97a2bd7c88  ph1_reference_layout.yaml  (7,498 bytes)
c0f704d690f2fd91e3e7ff9544574724fc7950b8ef911b62601a0ad314c9bba9  ph1_reference_scene.json   (15,866 bytes)
```

`sha256sum <file>` (or `Get-FileHash <file>` in PowerShell) must reproduce
these digests. Any key revision gets new hashes here in the same commit.

What is qualified?

The original STEP source was bound to the retained hand geometry. Both routes use all 59 source groups and 120 solids. This unscored exhibit includes the verified 49 rigid benchmark groups plus 10 flexible groups.

Exact NVIDIA BRep retained the solid counts and closely matched bounds. Finite surface samples agree closely in both directions. Mass parity failed for 47 groups, and the palm shell tessellation is nonmanifold. Passing a schema check does not resolve these failures.

No mechanical or physical validation and no MARB score is produced here.

Earlier Windows engine observation

One Windows CPU observation. NVIDIA did not demonstrate a speed win on this hand. Both use nominal 0.1 mm / 15° tessellation settings; these do not establish equivalent mesh error guarantees. The viewer retains this run's meshes; the GX10 panel reports separate ARM processing.
